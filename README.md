# Aws-static-website

## What is AWS?

AWS (Amazon Web Services) is a cloud computing platform by Amazon that provides a broad range of services such as computing, storage, networking, and analytics. It enables users and businesses to build, deploy, and manage applications globally using a flexible, pay-as-you-go model.

## What is an AWS S3 Bucket?

An AWS S3 Bucket is a cloud storage container used to store files and data objects in AWS. S3 provides reliable, scalable, and highly durable storage, making it ideal for hosting static content such as images, backups, and websites. Buckets support secure access, version control, and cost-effective storage management.

## What is AWS S3 Static Website Hosting?

S3 Static Website Hosting allows users to serve static web content (HTML, CSS, JS, and images) directly from an S3 bucket. When enabled, the website is accessible globally over HTTP, offering a fast, budget-friendly solution for hosting static websites without traditional web server management.
